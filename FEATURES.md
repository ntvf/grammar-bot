# Grammar Bot — Feature Backlog

1. **Voice messages** — transcribe a voice note, then fix/translate the transcript.
2. **Per-chat presets via inline mode** — let the inline result list offer Formal/Casual variants alongside the default.
3. **Undo** — `↩️` button that restores the previous version after a restyle or regeneration.
4. **Personal glossary** — words/names the bot must never change (brand names, nicknames).
5. **Group mode** — reply to any message in a group with `/fix` to get a corrected version.
6. **Learning digest** — weekly summary of the user's most frequent mistakes, built from the stored changes.
7. **Make language default** — from the 🌐 picker under a result, offer "use this language from now on".
8. **Premium limits** — Telegram Stars payment to lift the daily limit.
